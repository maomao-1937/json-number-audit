# json-number-audit 中文说明

在 JSON 交给使用 binary64 的程序之前，检查数字舍入、溢出、非零变零及安全整数范围风险。报告只含数字出现序号、词法类型、固定布尔标记和计数，不输出原始数字、键名、路径或片段。[English](README.md)

## 源码安装与运行

下载并解压源码（或克隆仓库），进入根目录，使用 Python 3.11 及以上版本：

```console
python json_number_audit.py examples/clean.json
python json_number_audit.py examples/risks.json
python json_number_audit.py examples/negative-zero.json
python json_number_audit.py --help
python -B -m unittest discover -s tests -v
```

仅使用标准库，无第三方依赖，无须 pip 安装、API Key、配置文件或环境变量。Windows 安装了启动器时，可用 `py -3.11` 替代 `python`。

输入必须是一个具名普通文件，严格 UTF-8 解码；允许一个初始 UTF-8 BOM，计入大小限制。支持顶层标量。拒绝重复的解码后键名、NaN/Infinity、不合法 JSON、不合法 UTF-8、键或值中的未配对代理码点；合法的转义代理对可以通过。不支持标准输入、URL 或多个 JSON 文档。

## 输出与退出码

标准输出是一行 JSON，标准错误为空。`numbers` 按原文数字出现顺序从 1 编号；`kind` 为 `integer`、`decimal` 或 `exponent`。各行包含以下布尔标记，`codes` 同时列出为真的固定标记名：

| 标记 | 含义 |
| --- | --- |
| `finite_inexact` | 转换后有限且非零，数值与原始精确有理数不同；不含变零情况。 |
| `overflow` | 转换得到正无穷或负无穷。 |
| `underflow_to_zero` | 原始非零数转换为零。 |
| `negative_zero` | 原始精确值为零且原文有负号，仅作信息提示。 |
| `outside_safe_integer` | 数学意义上的整数超出 `[-9007199254740991,9007199254740991]`。 |

`number_count` 是全部数字数目，`risk_count` 是至少有一项风险标记的数字数目（不计单独负零），`counts` 分别统计每项标记。一个数字可同时有多项标记，但只计一次风险。无数字则报告空列表。

退出码 `0`：无数值风险，只有负零也返回 0。`1`：存在上述风险。`2`：输入无效、不支持、不可读或发生操作错误，统一输出 `{"error":"invalid_input"}`，不回显输入信息。标准输出管道关闭时（包括帮助）安静返回 `0`；这是管道例外，不能据此认定审计成功。

`9007199254740992` 可以被 binary64 精确表示，但超出安全整数范围；本工具不会把它误称为已舍入。`1e3`、`1.0` 等写法按数学值判断是否为整数。先通过解析回调保留原始数字文本，再构造整数有理数并与 binary64 精确比例交叉相乘比较，不使用受 Decimal 精度上下文影响的运算。

## 限制与路径

固定上限：输入 2 MiB（含 BOM）、64 层数组/对象容器、100,000 个解析节点（含根、值、对象键）、每个数字 128 个字符、显式十进制指数绝对值 10,000。指数先按文本比较，再转整数、做幂运算；允许 `1e999`、`1e-999`，拒绝 `1e10001`。指数前导零不改变大小；小数位数最多额外增加一个受 token 长度限制的分母指数。没有运行时覆盖配置。

在任何 stat/open 之前，以保守跨平台规则拒绝 URI、驱动器相对路径、除 Windows 绝对驱动路径以外的冒号、ADS、UNC/网络路径（含混合分隔符）、设备前缀、通配符及保留/不支持的基本名。基本名比较不区分大小写，并在扩展名前去除尾随空格/点；包括 CON/PRN/AUX/NUL、CLOCK$/CONIN$/CONOUT$、COM/LPT 1–9（及上标 1–3）。这些是本工具主动拒绝的范围，不声称每个别名在所有系统都是真实设备。允许 Windows 绝对驱动路径；以 `-` 开始的文件名请加 `./`。

读取时再次确认普通文件并限制字节数。会跟随符号链接；普通文件无法证明其物理存储一定在本地，即使词法拒绝 UNC，挂载和链接仍可指向远端。需要本地存储时请使用可信本地目录。产品没有网络客户端、子进程、数据库操作或文件写入，只写标准输出；测试会创建临时合成文件和子进程。

## 验证边界

本工具检查当前 CPython 的 binary64 转换，不证明所有语言都会丢失数据，不做 schema、JSON 规范化、金额正确性或下游业务验证。保留任意精度整数/十进制的消费端可能没有这些风险。负零描述原文零值的负号，与负的非零数下溢变零分开判断。
